# ТЕНИ ФИНАЛ

Локальная точка восстановления финальной настройки теней, зафиксированная 2026-09-03 после ручной настройки всех существ.

Состав:

- `battlefield-shadow-tuning-v8.json` — точная копия рабочего редакторского файла: 56 вручную утверждённых существ и общий профиль `*`.
- `battlefield-shadow-effective-all-63.json` — развёрнутый набор для всех 63 существ каталога. Семь скрытых/служебных существ, которых нет в редакторе (`Arachna Spider`, `Dark Champion`, `Faerie Dragon`, `Imp`, `Phoenix`, `Skeleton`, `Zombie`), записаны явно с эффективным общим профилем.
- `battlefield-shadow-editor-state.json` — раскладка слотов редактора на момент сохранения.
- `battlefieldShadowTuning.ts.snapshot` — нормализация, профиль верхнего/нижнего ряда, масштабирование по глубине и синхронизация редактор ↔ игра.
- `battlefieldCreatureFraming.ts.snapshot` — масштаб и смещение самих фигур относительно клетки; это влияет на привязку тени к ногам.
- `RenderableUnit-shadow-sections.ts.snapshot` — формулы перспективы и участок построения/привязки тени к спрайту.

Контрольная сумма JSON: `510f184587d986ab7e198b6829a943841e44dbd5912282945d7e9e046d682010` (SHA-256).

Как устроено:

1. Верхняя игровая клетка получает профиль `top` 1:1 с редактором.
2. Между верхним и нижним краями поля длина, ширина и прозрачность линейно интерполируются.
3. Нижний профиль автоматически равен 90% длины верхнего; `bottomAlphaOverride` отдельно закрепляет прозрачность.
4. `offsetXCells` и `offsetYCells` задаются в долях клетки относительно точки ног фигуры.
5. `segmentLengthMultipliers` управляет четырьмя вертикальными полосами силуэта слева направо.
6. `contactAlpha` и `contactShadowVisible` управляют контактной тенью под ногами.
7. Игра строит тень из того же стабильного idle-кадра, против которого выполнялась настройка в редакторе.
8. Масштаб и смещение тела сохранены рядом, чтобы правильная тень не оказалась под иначе сдвинутой фигурой.

Восстановление:

1. Заменить `tmp/dev/battlefield-shadow-tuning-v8.json` содержимым сохранённого JSON.
2. При изменении утверждённой таблицы сверить `src/ui/battlefieldShadowTuning.ts` с snapshot.
3. При изменении посадки фигур сверить `src/ui/battlefieldCreatureFraming.ts` с snapshot.
4. При изменении математики тени сверить `src/scenes/RenderableUnit.ts` с сохранёнными секциями.
5. Перезагрузить редактор и игру: оба читают единый file-backed профиль.

Исходный рабочий слепок также остаётся в `design/battlefield-shadow-tuning-last-editor-save-v8.json` с той же контрольной суммой.
